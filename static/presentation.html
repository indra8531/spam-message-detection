PROJECT MOTIVATION

Problem Statement: The Smishing Epidemic

The Emerging Smishing Threat

  • Billions of fraudulent SMS and chat messages sent globally every day.
  • Vectors: Fake bank suspensions, customs redelivery fees, lottery windfalls.
  • Attacks exploit urgency and fear to trigger impulsive click-throughs.
  • Direct impact: Financial loss, identity theft, and credential harvesting.

Failure of Legacy Keyword Filters

  • Static blocklists fail completely against new phrasing and zero-day attacks.
  • Context blindness: Flag benign messages mentioning 'prize' or 'lottery ticket'.
  • Zero probability transparency or certainty indicators.
  • No explainability: Users are never told why a message was blocked.
PROJECT GOALS

Core System Objectives

1. Binary Detection

Accurately classify messages as SPAM or NORMAL using contextual NLP features.

2. Calibrated Confidence

Output true mathematical probabilities and confidence percentages for transparency.

3. Token Highlighting

Inline visual tags marking high/medium-risk threat terms with hover tooltips.

4. URL Threat Analysis

Extracts links, evaluates dangerous TLDs (.xyz, .top), and detects shorteners.

5. Audit History

SQLite database persistence with search, filtering, and detailed inspection modal.

6. Cyber UI/UX

Dual Dark/Light themes, zero page reloads, and 1-click test preset chips.

SYSTEM DESIGN

5-Stage Machine Learning Pipeline

Processing Pipeline Flow

  • Stage 1: Input Ingestion: Accepts text, URLs, numbers, and emojis.
  • Stage 2: Preprocessing: Tokenization, URL and currency normalization.
  • Stage 3: Feature Extraction: TF-IDF unigram & bigram matrix (8,000 max features).
  • Stage 4: Classification: Logistic Regression with probability calibration.
  • Stage 5: Result Generation: Threat scoring, token highlights, and safety advice.

Technology Stack Architecture

  • Frontend: HTML5, Glassmorphism CSS3, Vanilla ES6+ JS.
  • Backend API: Python 3.13, Flask 3.1, Gunicorn WSGI.
  • ML Engine: Scikit-learn, NumPy, Pandas, Joblib.
  • Storage: SQLite 3 with audit log tables.
ALGORITHM & MATH

TF-IDF Vectorization & Classification

TF-IDF Feature Representation

  • N-gram Range: (1, 2) captures words and phrases ("verify identity").
  • Sublinear TF scaling: 1 + log(tf) suppresses term spamming.
  • Canonical tokenization: <urltoken>, <phonetoken>, <currencytoken>.
  • Dimensions: 8,000 features optimized for <35ms latency.

Calibrated Logistic Regression

  • Loss Function: Log-Loss with L2 regularization (C=5.0).
  • Probability Sigmoid: P(Spam | X) = 1 / (1 + exp(- (w^T * X + b))).
  • Balanced Class Weights: Prevents majority class bias.
  • Direct Explainability: Model coefficients expose exact word weights.
HEURISTICS ENGINE

Behavioral Threat Taxonomy

🚨 Urgency & Coercion

"urgent", "action required", "account locked in 24 hours". Exploit fear to bypass cognitive scrutiny.

🎁 Lottery & Reward Scams

"congratulations", "won $1,000 gift card". Uses greed and novelty to bait victims.

🔐 Credential Harvesting

"verify password", "confirm OTP/PIN". Direct theft of authentication credentials.

📦 Delivery Smishing

"USPS package pending fee". Mimics postal carriers to steal credit card data.
